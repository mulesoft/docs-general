= MuleSoft Automation Credits 2.0
:description: Learn how MuleSoft Automation Credits 2.0 works, including credit consumption, allocation, and usage across MuleSoft products and services.
:keywords: mulesoft automation credits, automation credits 2.0, credit consumption, mulesoft licensing, credit allocation, anypoint platform credits, usage-based pricing
:page-aliases: rpa-home::ms-automation-credits-2.adoc, idp::ms-automation-credits-2.adoc, composer::ms_composer_automation_credits_2.adoc

Use MuleSoft Automation Credits 2.0 with Composer, IDP, RPA, Salesforce Flow Orchestration, MuleSoft for Flow: Integration, or a combination of these products, as more fully described in the applicable https://www.salesforce.com/company/legal/mulesoft-subscription-plan/[Subscription Plan] or Features and Entitlement Document.

If you have MuleSoft Automation Credits 2.0, view usage visibility through Anypoint Usage Reports. Sequoia handles monthly statements and overage billing.
