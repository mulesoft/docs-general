== Interface Details

=== Anypoint Platform UI

Use the UI for visual administration, full-lifecycle design, and security management.

* Design RAML and OAS specifications visually in Anypoint Code Builder and Design Center.
* Apply policies interactively and map governance strategies.
* Configure secret vaults, manage credentials, and set up providers.

=== Platform APIs

Use Platform APIs for programmatic control and automation.

* Drive CI/CD deployment pipelines on CloudHub 2.0 and Runtime Fabric.
* Apply policies and monitor compliance at scale.
* Manage environments, organizations, and access control programmatically.

=== MuleSoft MCP Tools

Use MuleSoft MCP tools to enrich context for AI agents and LLMs.

* Inspect assets and query metadata across Exchange without manual UI navigation.
* Summarize compliance status, missing policies, and governance rules for LLMs.
* Retrieve runtime status, operational health, and token usage in interactive agent workflows.
