= Get Started with Agent Fabric
:keywords: agent fabric, mulesoft, getting started, ai agents, learning map, anypoint platform
:page-aliases: agent-fabric::agent-fabric-get-started.adoc, agent-fabric::index.adoc
:page-article-style: learning-map

AI agents, MCP servers, and APIs are built across multiple platforms. That makes reuse, consistent security, and end-to-end LLM spend tracking difficult. Agent Fabric is the control plane for that landscape.

* Find every agent, MCP server, and API in the registry so you reuse what exists instead of rebuilding it.
* Make the APIs, applications, and agents you already run available as tools, so agents can take action without a rebuild.
* Put the same authentication, access, and security rules on live traffic, regardless of which platform built the agent.
* See where token spend goes, cap it, and stop paying a frontier model for work a smaller model can do.

The end-to-end journey for Agent Fabric consists of these tasks, each with links to relevant content to assist you in completing them.
