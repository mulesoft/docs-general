= Step 4. Test the API

In this step, you'll test your API using Anypoint Code Builder's debugging tools and add validation and logging to see what's happening inside your application.

== Step 4.1: Run and Test Your API

. Open the Run and Debug panel.
+
.Show me how
[%collapsible]
====
** Click the image:icon-run-debug.png["",15,15] (*Run and Debug*) icon in the activity bar.
** Use the keyboard shortcuts:
+
*** Mac: Cmd+Shift+d
*** Windows: Ctrl+Shift+d
** In the desktop IDE, select *View* > *Run*.
====

. Click *Run* to start your application.
+
The Output panel shows startup progress. Wait for `Application started successfully`.

. Open Postman and send a GET request:
+
[source,text]
----
GET http://localhost:8081/api/greeting?name=World
----

. Verify you receive:
+
[source,json]
----
{
  "message": "Hello, World!"
}
----
+
Your API works! Now let's add validation and debugging.

. Click *Stop* in the debug toolbar.

== Step 4.2: Add Validation

Now add validation to ensure your API handles invalid requests properly.

. In the canvas, navigate to your *get:\greeting* flow.

. From the component palette, search for *Validation* and drag *Is not blank string* into your flow before the *Transform Message* component.

. Click the validation component to configure it:
+
* *Value*: `#[attributes.queryParams.name]`
* *Message*: `"Name parameter is required"`

. Save your changes.
+
Your flow now validates that the `name` parameter is provided before processing the request.

== Step 4.3: Test the Validation

. Start your application using Run and Debug.

. In Postman, test with a valid name parameter:
+
[source,text]
----
GET http://localhost:8081/api/greeting?name=World
----
+
You should receive: `{"message": "Hello, World!"}`

. Test without the name parameter:
+
[source,text]
----
GET http://localhost:8081/api/greeting
----
+
You should receive a validation error with status 400.

. Click *Stop* in the debug toolbar.

Your API now validates input before processing.

== Step 4.4: Add Logging

Logging helps you see what's happening inside your flows.

. In the canvas, find your *get:\greeting* flow.

. From the component palette on the left, search for *Logger*.

. Drag the Logger component into your flow *before* the Transform Message.

. Click the Logger to configure it:
+
* *Message*: `"Received request for greeting"`
* *Level*: INFO

. Save your changes.

== Step 4.5: Test with Logging

. Open the Run and Debug panel.
+
.Show me how
[%collapsible]
====
** Click the image:icon-run-debug.png["",15,15] (*Run and Debug*) icon in the activity bar.
** Use the keyboard shortcuts:
+
*** Mac: Cmd+Shift+d
*** Windows: Ctrl+Shift+d
** In the desktop IDE, select *View* > *Run*.
====

. Click *Run* to start your application.

. Send a request with Postman:
+
[source,text]
----
GET http://localhost:8081/api/greeting?name=World
----

. In the Output panel (bottom of Anypoint Code Builder), select *Mule Maven Output*.
+
You'll see your log message:
+
[source,text]
----
INFO  [hello-world-impl].get:\greeting
  Received request for greeting
----

. Send a few more requests and watch the logs update.

. Click *Stop*.

== Step 4.6: Use Breakpoints for Debugging

Breakpoints pause execution so you can inspect what's happening.

. In the canvas, click in the left margin next to the Logger component.
+
A red dot appears, which represents a breakpoint.

. Open the Run and Debug panel.
+
.Show me how
[%collapsible]
====
** Click the image:icon-run-debug.png["",15,15] (*Run and Debug*) icon in the activity bar.
** Use the keyboard shortcuts:
+
*** Mac: Cmd+Shift+d
*** Windows: Ctrl+Shift+d
** In the desktop IDE, select *View* > *Run*.
====

. Click *Debug* (not Run) to start in debug mode.

. Send a request from Postman.

. Return to Anypoint Code Builder.
+
Execution pauses at the breakpoint. The debug toolbar appears at the top.

. In the Variables panel (bottom), expand *message* to see:
+
* *payload*: The current message content
* *attributes*: HTTP request details (headers, query params, URI)
* *vars*: Flow variables

. Click *Continue* (or press F5) to proceed to the next breakpoint.

. Click *Continue* again to complete the request.

. Click *Stop* when done.
