== Usage Types

[%header%autowidth.spread]
|===
| Product | Metric Description | Usage Details

| Composer
| Composer task: Any discrete action executed on a Composer connector, including but not limited to read, create, update, and delete.
| Calculated on a per action basis and aggregated as the total number of tasks completed within a billing cycle.

.2+| RPA (Robotic Process Automation)
| RPA bot minutes: The total duration (in minutes) spent running process automations across all active bot sessions.
| Calculated by tracking active execution time. Parallel bot sessions, multi-bot processes, and test-phase runs each count toward total bot minutes.

| RPA API Calls: Programmatic HTTP/REST requests used to trigger, monitor, or manage RPA bot workflows from external applications.
| Calculated on a per-request basis by summing all individual API calls made to the RPA Manager or RPA Bot API.

| Intelligent Document Processing (IDP)
| IDP Document Pages: A single physical or digital document page processed by IDP document actions.
| Calculated per page processed (each page of multi-page documents counts separately). IDP actions executed by RPA consume document pages and corresponding RPA Bot Minutes.

| MuleSoft for Flow: Integration
| Integration Tasks: A discrete execution of integration capabilities within Salesforce Flow.
| Calculated in real time per individual task execution, enabling immediate monitoring and aggregation of total consumption.
|===

== MuleSoft Automation Credits

A quantity of Automation Credits is included with certain MuleSoft Services, with the specific entitlement indicated on the Usage Details table on the Order Form for such Services. Automation Credits are consumed as you create and execute automations based on the rates in the following table. While MuleSoft Automation Credits 1.0 uses a conversion-based model, MuleSoft Automation Credits 2.0 and 3.0 use multiplier rates. Credit usage rates differ by subscription plan. Refer to the column that corresponds to your credit system.

| IDP and RPA usage in Anypoint Usage Reports

== Monthly Account Summary Emails

Salesforce sends usage-based billing reports to every MuleSoft Composer, Intelligent Document Processing (IDP), and Robotic Process Automation (RPA) customer on the 10th day of each month. By default, Salesforce sends these emails to the account's billing contact.

For more information about the reports, the list of recipients, and other details, see the https://help.salesforce.com/s/articleView?id=000390885&type=1[Monthly Account Summary Email FAQ^].
