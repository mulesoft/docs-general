= Browser-Based Workflow Automation with Bridget
:keywords: bridget, browser automation, legacy systems, integration, automation, enhanced experience

Bridget is a Salesforce application that automates browser-based workflows across business applications, especially systems without suitable APIs. It learns processes from recordings, user instructions, or system exploration, and then converts them into governed, reusable automations that connect to Anypoint Platform.

Open Bridget from the *Bridget* tab in the enhanced MuleSoft experience.

NOTE: The *Bridget* tab appears in the enhanced MuleSoft experience only if your organization has a Bridget entitlement.

== Key Benefits

Browser-Based Workflow Automation:: Automate tasks that people perform by hand in web applications, such as filling out forms and moving data between screens, to reduce manual data entry.
Legacy System Integration:: Integrate and synchronize data across systems that don't expose suitable APIs, without rewriting those systems.
Agent-Powered Workflow Learning:: Teach Bridget a task by recording it, describing it in instructions, or letting Bridget explore the application. This approach simplifies data entry for non-technical users.
Deterministic Execution:: Run a learned task the same way every time, so results are predictable and auditable.
Automatic Healing:: Adapt automations when the target application's interface changes, reducing maintenance.

== Use Cases

Use Bridget to automate processes that previously required people to work through application screens by hand:

Supplier Onboarding:: Instead of staff manually keying supplier details, certifications, and banking information into onboarding forms, Bridget enters the data. Mule applications then validate it and route it to your ERP system.
Legacy Data Entry and Migration:: Instead of staff re-entering records into a legacy application's interface, Bridget performs the same on-screen actions, including bulk migration of historical data.
Multi-System Workflows:: Instead of staff entering the same data into several systems, Bridget enters it once and Mule applications route it to CRM, ERP, and analytics systems.

== Limitations and Availability

Desktop Applications:: Bridget automates only browser-based applications. It doesn't support desktop applications.
Dependencies:: Bridget requires active integration with Anypoint Platform services.
Supported Regions:: Bridget is available in North America (us-east-1, us-west-2).


== Before You Begin

Before getting started, make sure you have:

* An Anypoint Platform account with access to the enhanced MuleSoft experience
* A Bridget entitlement for your organization
* One of these Bridget roles, assigned by an organization administrator:
** Bridget User: Runs automations
** Bridget Manager: Configures and manages automations, and includes Bridget User permissions
** Bridget Admin: Provides full administrative control, and includes Bridget Manager permissions

For more information, see xref:agent-fabric::get-started.adoc#permissions[Enhanced Experience Permissions].

== Access Bridget

From the enhanced MuleSoft experience, navigate to the *Bridget* tab and click *Go to Bridget*.

If you don't see the *Bridget* tab, check with your organization administrator that your organization has a Bridget entitlement and that you have a Bridget role.
