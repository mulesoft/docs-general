= Java Support
:keywords: java support, mule runtime, java version, java 17, java 25, mulesoft java compatibility, version support matrix

include::reuse::partial$java8-eoss-banner.adoc[tag=java8-eoss]

MuleSoft follows Java's long-term-support (LTS) release cadence. Mule runtime 4.6 added support for Java 17 LTS, and Java 25 LTS support is planned for Mule runtime 4.14. Each Mule runtime version supports specific Java versions, and the Java version you use affects your integration apps, connectors (Anypoint connectors and custom connectors), Mule Gateway policies, and API proxies.

Use this topic to find the Java versions that each Mule runtime version supports. Then, go to the topic for the Java version you want to use:

* xref:java-17-support.adoc[]: Plan and complete your upgrade to Java 17.
* xref:java-25-support.adoc[]: Plan your upgrade to Java 25.
