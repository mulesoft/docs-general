= Securing Services in Your Portfolio
:keywords: securing services, external vaults, secrets manager, credentials, Akamai API Security, risk correlation, rogue agents, Azure Key Vault, HashiCorp Vault, portfolio, anypoint platform

Authenticate model proxies with keys from an external vault, map Akamai findings onto APIs and MCP services in your enhanced MuleSoft experience portfolio, and contain rogue agents before they leak data or inflate costs. 

* xref:exp-akamai-risk-correlation.adoc[Correlate Risk Using Akamai API Security]
+
Connect Akamai API Security to map risk scores, findings, and incidents onto existing APIs and MCP services in *Portfolio*.

* xref:exp-vaults-manage.adoc[Use Credentials Stored in External Vaults]
+
Use API keys stored in an external vault to authenticate model proxies without storing those keys in MuleSoft.

+
Apply Rogue Agent Detection and Agent Kill Switch policies on model proxies to flag anomalous agent behavior and quarantine rogue agents.
