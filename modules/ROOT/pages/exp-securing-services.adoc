= Securing Services in Your Portfolio
:keywords: securing services, external vaults, secrets manager, credentials, portfolio, anypoint platform


Keep API keys and other credentials for portfolio services in the secrets manager you already run. Register an external vault so MuleSoft stores only secret names and paths. Services such as model proxies resolve the value from the vault at runtime instead of storing the key in MuleSoft.

* xref:exp-vaults-manage.adoc[]
+
Connect AWS Secrets Manager, Azure Key Vault, or HashiCorp Vault, choose an authentication method, and sync secret metadata for use in the enhanced experience.
