= Step 1. Prerequisites for Building an API-Led Solution


Before you begin building your API-led solution, verify that you have the required tools and access:

* Username and password for your Anypoint Platform organization. If you don't have Anypoint Platform yet, create a Trial organization on Anypoint Platform.
+
link:https://anypoint.mulesoft.com/login/#/signup["Create a Trial organization^", role="button-primary"]

* Download Anypoint Code Builder. 
+
link:https://www.mulesoft.com/lp/dl/anypoint-mule-studio["Download Anypoint Studio^", role="button-primary"]

* Required Permissions:
** *Anypoint Code Builder Developer*
** *Mule Developer Generative AI User*
+
Enables MuleSoft Vibes features
** *Design Center Developer*: Allows API specification creation
** *Exchange Contributor*: Enables publishing assets to Exchange
** *CloudHub 2.0 Deploy*: Allows deployment to CloudHub 2.0

* *Einstein Enabled*: MuleSoft Vibes requires Einstein to be enabled in Access Management. See xref:access-management::enabling-einstein.adoc[Enabling Einstein for Anypoint Platform].

== Required Tools

Install these tools for testing APIs:

* *REST Client*: Download and install a REST client such as:
** link:https://www.postman.com/downloads/["Postman^", role="button-primary"]
** link:https://github.com/advanced-rest-client/arc-electron/releases["Advanced REST Client^", role="button-primary"]
+
This tutorial uses Postman for examples, but any REST client works.

== Recommended Knowledge

While this tutorial guides you through each step, familiarity with these concepts helps:

* *REST APIs*: Understanding HTTP methods (GET, POST, PUT, DELETE), status codes, and JSON
* *API Specifications*: Basic knowledge of OpenAPI Specification (OAS) or RAML
* *Integration Concepts*: General understanding of how systems communicate

== CloudHub 2.0 Setup

For CloudHub 2.0 deployments, you need:

* A CloudHub 2.0 Shared Space in your organization. Anypoint Platform trial accountsinclude a default Shared Space.
+
See xref:cloudhub-2::ch2-shared-space-about.adoc[About Shared Spaces].

* At least one environment (such as Sandbox or Development) configured for CloudHub 2.0 deployments.
+
See xref:cloudhub-2::ch2-environments-about.adoc[About Environments].
