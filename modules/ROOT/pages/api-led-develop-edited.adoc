= Step 3. Develop the API

Now that you've created an API specification, you'll turn it into a working Mule application. Anypoint Code Builder includes an embedded Mule runtime for local testing. Later, you'll deploy your application to xref:cloudhub-2::ch2-deploy.adoc[CloudHub 2.0], where it runs on Mule runtime in the cloud.

== Step 3.1: Create the Implementation Project

. In Anypoint Code Builder, open the Command Palette.
+
.Show me how
[%collapsible]
====
* Use the keyboard shortcuts:
** Mac: Cmd+Shift+p
** Windows: Ctrl+Shift+p
* In the desktop IDE, select *View* > *Command Palette*.
====

. Type and select: *MuleSoft: Develop an Integration*.

. Select *Create New Project*.

. Configure the project:
+
* *Project Name*: `hello-world-impl`
* Select *Import API Specification*: *From Exchange*.
+
NOTE: If your spec isn't in Exchange, select *From Local File* and browse to `hello-world-api.yaml`
* Enable *Scaffold flows from this API specification*.

. Click *Create Project*.
+
Anypoint Code Builder generates:

* HTTP Listener configuration (receives requests)
* APIkit Router (routes to your endpoint)
* A flow for your GET `/greeting` endpoint
* Error handlers

. In the Explorer, open `hello-world-api.xml`.
+
The canvas displays your scaffolded flows.

== Step 3.2: Understand the Scaffolded Structure

. In the canvas, you'll see these flows:
+
* *hello-world-api-main*
+
HTTP Listener that receives requests on port 8081
* *get:\greeting:hello-world-api-config* 
+
Your GET endpoint implementation
* Error handling flows

. Click the *HTTP Listener* component to review:
+
* *Path*: `/api/*` (receives all API requests)
* *Port*: `8081` (local development port)

== Step 3.3: Implement the Hello World Logic

Now add the logic to return your greeting.

. Navigate to the *get:\greeting:hello-world-api-config* flow in the canvas.

. Click the *Transform Message* component in the flow.

. Replace the DataWeave code with:
+
[source,dataweave]
----
%dw 2.0
output application/json
---
{
  message: "Hello, " ++ attributes.queryParams.name ++ "!"
}
----
+
This DataWeave script reads the `name` query parameter and returns a personalized greeting.

. Save your changes (Cmd+S on Mac, Ctrl+S on Windows/Linux).

That's it! Your API is implemented and ready to test.

== What Just Happened?

Let's understand what you used:

* *Scaffolding*
+
Anypoint Code Builder generated the project structure from your specification.
* *HTTP Listener*
+
Receives incoming HTTP requests on port 8081.
* *APIkit Router*
+
Routes requests to the correct endpoint flow.
* *DataWeave*
+
MuleSoft's transformation language for creating responses.
* *Canvas*
+
Visual editor for building flows.
* *Run and Debug*
+
Built-in testing environment.
